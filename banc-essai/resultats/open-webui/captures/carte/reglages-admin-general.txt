Contexte système pour la mémoire.

Load selected skills on demand

Load selected and model-attached skills when needed instead of including instructions upfront. Explicit skill mentions still load immediately. Requires built-in skill tools; otherwise instructions load upfront.

Skill Read Limit

Maximum characters per skill read. Longer instructions open as a preview. Leave empty to use the default.

Skill Preview Length

Characters shown when instructions exceed the read limit. Cannot exceed that limit. Leave empty to use the default.

Chat Read Limit

Maximum characters returned when a model reads a previous chat. The newest messages are kept. Leave empty for no limit.
